# Can They Make Snow? theme

The frontend theme for cantheymakesnow.com. See the project README in the repository root for setup.

- `pages/home.htm`: the single-screen app (lookup form, result, map)
- `partials/`: header, footer, map and snowfall partials
- `assets/css/custom.css`: all site styles. Bootstrap 5.3 is loaded from jsDelivr in `layouts/default.htm`.
- `assets/css/tw.css`: Tailwind build output (`npm run build`)

Originally based on the [Prismify Bootstrap starter kit](https://github.com/prismify/oc-bootstrap-theme), MIT licensed (see `LICENSE.md`).
